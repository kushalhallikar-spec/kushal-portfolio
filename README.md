## ✦ About This Portfolio

> A cinematic, dark-themed personal portfolio built from scratch with **React + Vite** — no UI libraries, pure custom CSS. Designed to stand out, built to perform.

- 🎬 **Cinematic video hero** with mute/unmute control
- 🖱️ **Custom animated cursor** with smooth lag effect
- 🌊 **Scroll-triggered fade-in** animations via IntersectionObserver
- 📱 **Fully responsive** — desktop, tablet, and mobile
- 🃏 **Sticky project cards** with mock UI previews
- ⚡ **Sub-1s build time** with Vite

## ✦ Run Locally

```bash
# Clone the repo
git clone https://github.com/kushalhallikar-spec/kushal-portfolio.git

# Move into project
cd kushal-portfolio

# Install dependencies
npm install

# Start dev server
npm run dev
```

Open → `http://localhost:5173`

> **Note:** Place `intro.mp4` and `photo.jpg` inside the `public/` folder for the hero section to work correctly.
